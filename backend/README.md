# 🧠 Backend: крипто‑оракул для предсказания движения цены
Бэкенд‑сервис для крипто‑оракула. Модель предсказывает направление движения цены (вверх/вниз) на основе технических индикаторов и тональности новостных данных.

## 🛠️ Стек технологий
- **Python 3.12**
- **Fastapi**
- **SQLModel / SQLAlchemy**
- **Httpx**
- **Pydantic**
- **CCXT**
- **TextBlob**
- **Scikit-learn**
- **Joblib**

## 📊 Как работает оракул

Модель использует логистическую регрессию для бинарной классификации: «цена пойдёт вверх» или «цена пойдёт вниз».

Входные признаки
 - **Отношение цены закрытия к SMA(20)** — нормализованный показатель на 1‑часовом графике (последние 20 свечей). Помогает оценить отклонение цены от средней.
 - **Полярность (позитивность/негативность) новостей** — метрика sentiment из TextBlob. Показывает общий эмоциональный окрас новостной ленты.
 - **Объективность/релевантность новостей** — оценка нейтральности текста и его связи с конкретной монетой. Используется как дополнительный признак, снижающий влияние «шумовых» заголовков.
Такой набор признаков позволяет совмещать технический и новостной контекст — это базовая версия модели, которую можно дообучать по мере накопления истории прогнозов и фактических цен.



## 🚀 Инструкция по запуску

### Локальный запуск без Docker

1. Установи зависимости:
```bash
pip install -r requirements.txt
```

2. Настрой переменные окружения (.env или export) — путь к БД, ключи API и т. д.
```bash
# список токенов для предсказания в формате json
TOKENS="{'BTC', 'ETH', 'BNB', 'DOGE', 'SOL', 'XRP', 'ONDO'}"  

# настройки для получения новостей по api, источник newsapi.org
NEWS_API_KEY=your-secret-api-key
# можно использовать фейковые новости, тогда api не будет использоваться
NEWS_FAKER=False

# биржа источник цен
CCXT_EXCHANGE: str = 'binance'

# база данных
DB_URL: str = 'sqlite+aiosqlite:///db.sqlite3'

# дефолтное имя модели, по мере накопления данных для каждого токена тренируется своя модель
DEFAULT_MODEL_NAME: str = 'default'
```

3. Запусти предтренировку:
```bash
# python -m src.warmup -h (для получения справки)
python -m src.warmup collect
python -m src.warmup train
```


4. Запусти сервер:
```bash
fastapi dev
```
